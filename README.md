# Контур — мини-CRM для объектов и задач

Первый этап тестового задания: интерактивный UI-прототип на React и TypeScript.

```bash
pnpm install
pnpm dev
```

Данные этого этапа хранятся в `localStorage` браузера. Переключатель ролей нужен для проверки интерфейсных сценариев. Он **не обеспечивает безопасность**: авторизация, Supabase, RLS, ограничения переходов в базе и защищенная история статусов будут реализованы на следующем этапе. Не используйте этот прототип с реальными данными.
